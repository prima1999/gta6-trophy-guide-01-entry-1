Vice City Platinum — a complete offline guide and tracker for all 55 PS5 GTA 6 trophies: checklists saved in your browser, filters, a spoiler setting, a platinum roadmap, missable flags, and a step-by-step guide with sources for every trophy. Fully offline — no account, no upload, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
